# Natural Navigation

## Install

1. Copy mods folder to the same folder where exe is located.
2. Run (double-click) `install.bat`

```
|- ...
|- GenerationZero_F.exe
|- gz_nav
    |- install.bat
    |- locations.txt
    |- README.md
    |- settings.ini
    |- uninstall.bat
    |- xinput9_1_0.dll
```

## Uninstall

1. Run (double-click) `uninstall.bat`

## Usage

1. Configure game via `settings.ini`
2. Start game
