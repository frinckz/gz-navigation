# Natural Navigation

## Install

1. Copy the folder to the same folder where exe is located.
2. Run (double-click) `install.bat`

```
|- ...
|- GenerationZero_F.exe
|- gz_nav/
    |- install.bat
    |- uninstall.bat
    |- ...
```

## Uninstall

1. Run (double-click) `uninstall.bat`

## Usage

1. Select mode setting `mode` in `settings.ini`
   * `mode=0` Normal mode
   * `mode=1` Guesser mode (Use the map to make a guess)
2. Start Game
